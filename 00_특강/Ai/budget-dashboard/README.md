# 가계부 대시보드 (Vue3 + Pinia + json-server)

## 설치
```
npm install
```

## 실행 (json-server + vite 동시 실행)
```
npm start
```

- 앱: http://localhost:5173
- json-server: http://localhost:3001/transactions

## 기술 스택
- Vue 3 (Composition API, ES6)
- Pinia (상태 관리, axios로 json-server 연결)
- Vue Router
- Bootstrap 5
- FontAwesome
- Google Charts (vue-google-charts)
- json-server (mock REST API)
